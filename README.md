# Projet POO

1)	fichier_texte.py : Lit le fichier essai.ac, nettoie son contenu et extrait des statistiques (caractères, mots), et génère un nuage de mots.
2)	convertisseur_ac_tsv.py : Convertit le fichier .ac en .tsv.
3)	convertisseur_tsv_ac.py : Transforme le fichier .tsv en format .ac. 
4)	convertisseur_txt_aa_tsv.py : Crée le fichier .aa à partir de textes bruts et les convertit en .tsv avec des annotations.
5)	convertisseur_tsv_conll.py : Convertit le fichier .tsv en format ConLL.
6)	ac_to_aam_example.py : Utilise des expressions régulières pour annoter des personnages et des actions dans un texte, générant des annotations .aam.
